The numbered PNGs are byte-identical reviewed TUM hall frames. Some original hall frames contain only the panel texture and are not town-scene building sprites.

`dark-cathedral-v1.webp` is a new transparent illustration for the mobile Necropolis town panorama and construction cards. It was generated for this interface, using the existing Necropolis sprites as a style reference, then exported at 256 pixels with lossless alpha. It is not presented as an original WoG/TUM sprite. It changes no construction costs, prerequisites, availability or creature rules.
