The numbered PNGs are byte-identical reviewed TUM hall frames. Several original hall frames contain only panel texture and are not usable as town-scene sprites. They remain available for source provenance and are not used for the new panorama illustrations.

The nine WebP illustrations registered in `building-art.mjs` are new transparent artwork for the mobile town panoramas and construction cards. Each uses the owning faction's existing sprites as a style reference and is exported at 256 pixels with lossless alpha. These are interface illustrations, not original WoG/TUM sprites. Base and improved buildings use the same illustration, with their native names and recruitment states.

Only built structures are drawn. Clicking the real dwelling opens its native eighth-tier recruitment family. There is no floating construction/recruitment banner, and unbuilt projects remain accessible through the construction menu. These assets change no construction costs, prerequisites, availability, upgrades or creature rules. Goonk uses its existing, separately registered town-building artwork and native seven-tier roster.
