# Mysterious Cave native port contract

Source: Third Upgrade Mod `Data/s/Mysterious Cave.erm`, SHA256
`d4b9286b930cfc32a742571f21513170fdd243f3bccf08d9a84b14dd53c13c97`.
The inspector inventories 33 `!?` callbacks and one `!$OB63/56` callback.
The 45 reward labels are 20–64; 10–19 mean empty.

The production Cave object keeps persistent state in rewardable configuration
variables and uses existing server packets. The controller is the Cave with
lowest object instance ID. Daily rolls are shared, with all 14 original draws
(including the experience draw immediately overwritten by another draw).
Each human turn refreshes those rolls and decrements every hero's Cave timers,
including dismissed/defeated heroes retained in the tavern pool. Timer keys use
the stable hero type JSON key, not an object or registry number. Older native
object-ID keys migrate additively before the duplicate-turn receipt guard. A
Builder expiring in the pool releases the global lock on schedule, while its
suppressed prototype specialty is restored when the hero is activated again.
AI turns activate the last human's Scourge target. HO stores persistent
per-colour interaction bans on the hero: changing the global selected target
does not clear a previous hero's bans; only that hero's expiry does. Native
state preserves this mask, including across ownership changes and rehiring. Weekly rolls run on each
human turn on weekday one, in source subtype56 then subtype55 order.

## Source behavior takes precedence over prose

- Spell tome costs 300000 gold, not the 100000 mentioned by some prose.
- The final experience draw is 500–2000 times month; the discarded draw remains
  part of the RNG stream.
- Builder begins at seven, despite a description saying nine.
- Choices44/45 reroll to daily blessing46–48. Watcher hints are an INI option.
- Obelisks, guilds and remote visits select the first eligible source cursor
  object, not a random eligible object.
- Prison-level reset and blacksmith ghost removal are disabled in this source.
- Weekly reset keeps the old subtype if a hero stands on the Cave. A visited
  subtype55 is therefore still unavailable until a weekly reset without an
  occupying hero, even though its PO visit counter was reset. Native state
  keeps subtypeVisited separate from that counter and preserves RNG pass order.
  AI visits and empty human visits set PO15 without replacing subtype56; they
  remain in the first weekly RNG pass.

## Explicit native representation exception

The Goonk Castle-derived town explicitly uses Castle demolition fees, salvage,
dependencies and damaged Castle graphics. Goonk is an additional rebuild
destination alongside all nine source factions. No new tariff is invented.

At faction change the native port removes every old building, including native
T8 IDs outside the original six-byte standard mask. Retaining these IDs can
reference buildings absent from the new faction and leave undefined state.
This correction was authorized by the owner; it does not grant extra buildings
or refund their costs.

Native presentation uses summarized reward text, ordinary VCMI dialogs and
icons, and the tactile Builder panel. It does not reproduce the source's
transient `UN:A` icon-table edits or play its `SN:P` voice/sound snippets.
These are explicit presentation adaptations; their gameplay results are
implemented by native operations.

## Validation boundary

and four viewport checks have passed. Building/rendering success alone is not
proof of gameplay equivalence.
