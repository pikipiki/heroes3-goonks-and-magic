# Joining creatures and battle inspection

Creature and neutral reward overflow windows now use the same mobile troop exchange as adventure garrisons. The native query and ownership checks remain authoritative. The two seven-slot armies support selection, movement, merging, swapping and quantity selection. Finishing with remaining offered troops lists those troops and asks for explicit confirmation; cancelling returns to the roster. Landscape keeps commands on the right and allows vertical scrolling.

The battle action bar has **Inspect**: select any living allied or enemy stack to open its native creature window. The current creature portrait also has an information affordance. Inspection is available in a stable manual phase, never during autocombat or an animation. It uses action 114 exclusively to create a non-popup `CStackWindow`; it cannot move, attack or cast. The sheet exposes live combat attack/defense, damage, HP, speed, shots, retaliations, abilities and active spells. Closing returns to the same combat view and turn. Hero/map creature sheets retain their existing behavior.

Validation: WebAssembly `ninja -j32 html5`, 773 passing unit tests (48 skipped), catalog byte verification, and native Chromium/English and WebKit/French scenarios covering full-army joining, swaps, discard confirmation/cancellation, portraits, three mobile orientations/sizes, enemy/ally inspection and both battle views without changing the combat state. See `outputs/joining-inspection-0.4.235/validation.json`. Private maps, saves and diagnostic state are not published.
