HEROES GOONK — PUBLICATION

NETLIFY
1. Ouvre https://app.netlify.com/drop
2. Décompresse heroes-goonk-netlify-pages.zip, puis glisse le dossier
   obtenu (avec index.html à sa racine) dans la zone de dépôt.
3. Ouvre l’adresse HTTPS fournie.

Le ZIP fait environ 137 Mo : pour un envoi plus fiable, tu peux aussi
importer le dépôt GitHub dans Netlify. Les réglages sont déjà fournis
dans netlify.toml. Les prochains commits envoyés publient les mises à jour.

GITHUB PAGES — AUTOMATIQUE POUR CE DEPOT
https://pikipiki.github.io/heroes3-goonks-and-magic/
Chaque push sur main construit et publie automatiquement le site.
Les étapes ci-dessous servent à configurer une nouvelle copie du dépôt.

1. Envoie le dépôt heroes-goonk sur GitHub.
2. Settings > Pages > Build and deployment > Source : GitHub Actions.
3. Actions > Publish Heroes Goonk to GitHub Pages > Run workflow (main).
4. Le lien public apparaît dans le déploiement GitHub Pages.
Les prochains envois sur main publient automatiquement les mises à jour.

POUR RECREER L’ARCHIVE
Dans le dossier du projet : npm run package:web
Résultat : outputs/heroes-goonk-netlify-pages.zip

Les données de base Heroes III sont intégrées dans le déploiement par morceaux
vérifiés de 4 Mo maximum. Aucun import manuel de fichiers n’est nécessaire : le
jeu se synchronise directement au premier lancement.
Sur GitHub Pages, laisse la page terminer son premier rechargement.
Netlify et GitHub Pages ont des stockages locaux distincts.
